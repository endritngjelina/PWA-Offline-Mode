# PWA Offline Mode

A Progressive Web App (PWA) project demonstrating how modern web applications can continue functioning even when the user loses internet connectivity.

This repository contains multiple development iterations, allowing you to follow the evolution of the project and explore different approaches to implementing offline functionality.

## Features

- 📶 Offline-first web experience
- ⚡ Service Worker support
- 💾 Local asset caching
- 🔄 Automatic cache updates
- 📱 Installable as a Progressive Web App
- 🌐 Works with intermittent or no internet connection

## Project Structure

```
PWA offline mode 0.html    → Initial prototype
PWA offline mode 1.html    → Feature improvements
PWA offline mode 2.html    → Additional refinements
PWA offline mode 3.html    → Latest version
```

Each version represents a stage in the application's development process.

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/endritngjelina/PWA-Offline-Mode.git
```

2. Open the project in your preferred code editor.

3. Because PWAs require a secure context, run the project using a local web server instead of opening the HTML file directly.

Examples:

Using VS Code Live Server:

- Install the **Live Server** extension
- Right-click the HTML file
- Select **Open with Live Server**

or using Python:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```
